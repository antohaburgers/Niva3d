# OFFROAD NIVA v0.06.2 PWA

Самостоятельная версия для GitHub Pages. Ничего устанавливать или собирать для публикации не нужно. Все файлы игры локальные, внешних моделей, CDN и зависимостей нет.

## Загрузка на GitHub

1. Распакуйте архив.
2. Создайте репозиторий, например `offroad-niva` (для GitHub Free — публичный).
3. Загрузите **содержимое** распакованной папки в корень репозитория. `index.html`, `game.js`, `physics.js`, `surfaces.js` и `engine-audio.js` должны лежать рядом, не внутри дополнительной папки. Сам ZIP загружать вместо файлов не нужно.
4. Откройте Settings → Pages → Build and deployment → Source: Deploy from a branch.
5. Выберите Branch: main, Folder: / (root), нажмите Save.
6. После завершения публикации откройте адрес, показанный в Pages, в Safari или Chrome. На iPhone сначала проверьте именно Safari, отдельно от встроенного просмотра приложения.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Управление

- Левый стик: только руль.
- GAS справа: газ. BRAKE: тормоз, после остановки — задний ход.
- Камера: нажмите на свободный участок 3D-сцены и сместите палец; стик невидимый, его центр — место первоначального касания. После отпускания камера ждёт 1.6 секунды и плавно возвращается. Мышью — перетаскивание.
- Газ, руль и камера работают отдельными указателями, одновременно.
- ТРАНСМИССИЯ раскрывает H/L, C LOCK, R LOCK. WAIT означает ожидание безопасных условий.
- WASD / стрелки: движение. Пробел / кнопка РУЧНИК: задний ручник.
- НА СТАРТ возвращает машину. ЗВУК включается первым касанием.
- Телефон: горизонтальная ориентация; в вертикальной игра на паузе.

## Проверка

Старый полигон сохранён: справа диагональные неровности, слева подъём, позади твёрдое покрытие. Новые участки правее: рыхлая земля, лёгкая грязь, глубокая грязевая яма и брод. В грязи попробуйте HIGH, LOW и блокировки; удержание полного газа может дать больше буксования, чем продвижения. Для дозирования тяги на телефоне отпускайте и снова нажимайте GAS.

В версии 0.06.1 руль перенесён влево, видимый стик камеры удалён. На устройствах с сенсорным управлением ограничено разрешение отрисовки и отключено сглаживание WebGL. HUD обновляется 10 раз/сек; данные колёс переиспользуются без создания нового массива на каждом шаге физики. Физика и её фиксированный шаг сохранены.

Причина зависания во встроенном просмотре пока не установлена. Переход на Pages сам по себе не гарантирует исправления. Сравните отдельный Safari и встроенный просмотр: момент зависания, включён ли звук, работает ли НА СТАРТ и продолжается ли звук. Реальный FPS и мультитач на iPhone требуют проверки устройством.

Локальный запуск: `python3 -m http.server 8000`, затем http://localhost:8000. Не открывайте index.html через file:// — модульные скрипты требуют HTTP.

Автоматические проверки: Node.js 22+ → `npm test`. Устанавливать npm-пакеты не нужно.

## Что внутри

- index.html: горизонтальный интерфейс и левый руль.
- game.js: WebGL-сцена, низкополигональная Нива, управление, камера и полигон.
- physics.js: подвеска четырёх колёс, двигатель, автомат, раздатка и дифференциалы.
- surfaces.js: коэффициенты материалов и глубины, раздельный контакт колёс.
- engine-audio.js: синтезированный звук двигателя.
- tests/: проверки физики, поверхностей, управления, ориентации и звука.

Частицы, следы, свет, повреждения и генерация мира ещё не добавлены. Деревья — декорации, препятствия полигона используют геометрию поверхности. Это игровая упрощённая физика.


## PWA и защита жестов (v0.06.2)

Публикуйте содержимое этого архива вместо прежней версии. В корне должны лежать `sw.js`, `manifest.webmanifest`, `pwa.js`, `browser-guard.js` и папка `icons`, вместе с остальными файлами. Путь к приложению относительный: подходит для GitHub Pages `/имя-репозитория/`.

На iPhone: откройте опубликованный HTTPS-адрес в Safari → Поделиться → На экран «Домой» → Добавить. Запускайте с нового значка. На Android — меню браузера → Установить приложение / Добавить на главный экран. Ориентацию некоторые браузеры, включая iOS, не блокируют принудительно: при необходимости поверните устройство сами.

После первого полного запуска с интернетом дождитесь загрузки игры и подождите несколько секунд для сохранения файлов. Затем закройте приложение, включите авиарежим и откройте с иконки. Все файлы игры и звук локальные; офлайн-режим готов после успешной установки service worker. Браузер может удалить кеш при нехватке места.

Защита блокирует прокрутку страницы, pull-to-refresh внутри страницы, pinch/double-tap zoom, выделение, контекстное меню и перетаскивание. Pointer Events и мультитач игры сохранены. Системные жесты iOS (край экрана, переключение приложений, шторки) веб-страница полностью заблокировать не может.

Обновления: меняйте VERSION в sw.js и версии URL всех скриптов вместе. Новый кеш создаётся целиком; обновление не перезагружает игру посреди заезда. После новой публикации откройте приложение с интернетом, затем закройте все его вкладки/окна и запустите снова. На телефоне старый установленный экземпляр и вкладка браузера могут задерживать обновление.

Проверено автоматически: манифест, все пути офлайн-файлов, установка и очистка кеша только своего приложения, запуск офлайн из корня и подпапки, защита браузерных жестов. Установка на настоящий iPhone и офлайн-перезапуск требуют проверки устройством.
